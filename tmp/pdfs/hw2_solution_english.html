def open_uniform(size, generator=rng):
    # Exclude 0 and 1 before logarithms; clipping affects only floating-point endpoints.
    return np.clip(generator.random(size), np.nextafter(0., 1.), np.nextafter(1., 0.))

1. Continuous distributions: inverse transform sampling¶

Let $U\sim\mathrm{Unif}(0,1)$. For a continuous, strictly increasing CDF, set $X=F^{-1}(U)$. Then $$P(X\le x)=P(U\le F(x))=F(x).$$ Solving $u=F(x)$ gives the following transformations.

Part Sampling transformation Theoretical PDF Mean; variance
(a) Logistic $X=\log U-\log(1-U)$ $e^{-x}/(1+e^{-x})^2,\ x\in\mathbb R$ $0;\ \pi^2/3$
(b) Rayleigh $X=\sqrt{-2\log(1-U)}$ $xe^{-x^2/2},\ x>0$ $\sqrt{\pi/2};\ (4-\pi)/2$
(c) Exponential $X=-\log(1-U)$ $e^{-x},\ x>0$ $1;\ 1$

Algorithm: Independently draw one uniform variate for each sample and apply the relevant transformation. log1p(-u) computes $\log(1-u)$ stably. Generating $n$ samples takes $O(n)$ time and requires no rejection.

2. Discrete distributions: a general inverse-CDF algorithm¶

Let the ordered support be $x_0<x_1<\cdots$, let $p_k=P(X=x_k)$, and define $C_k=\sum_{j=0}^kp_j$, with $C_{-1}=0$. Draw $U\sim\mathrm{Unif}(0,1)$ and set $$K=\min\{k:U\le C_k\},\qquad X=x_K.$$ Since $P(C_{k-1}<U\le C_k)=C_k-C_{k-1}=p_k$, this algorithm is correct. Zero-mass entries cause no problem; a uniform draw exactly on a boundary has probability zero.

For finite support of size $m$, cumulative probabilities take $O(m)$ preprocessing time, followed by $O(\log m)$ binary search per sample. For infinite support, accumulate until the CDF exceeds the current uniform draw. The batch implementation below extends the genuine CDF beyond the largest uniform draw in the batch: it neither truncates nor renormalizes the distribution.

(a)-(d). PMFs, recurrences, and counting conventions¶

  • Bernoulli(0.5): $P(X=0)=P(X=1)=1/2$, so $X=\mathbf1\{U>1/2\}$. The mean is $1/2$ and the variance is $1/4$.
  • Binomial(20,0.5): $P(X=k)=\binom{20}{k}2^{-20}$ for $0\le k\le20$. Start with $p_0=2^{-20}$ and use $p_{k+1}/p_k=(20-k)/(k+1)$. The mean is $10$ and the variance is $5$.
  • Geom(0.5): Here $X$ counts trials up to and including the first success: $P(X=k)=2^{-k}$ for $k\ge1$. Since $F(k)=1-2^{-k}$, use $X=\lceil\log(1-U)/\log(1/2)\rceil$. The mean and variance are both $2$. Under the alternative failures-before-success convention, use $X-1$, whose mean is $1$.
  • NBin(10,0.5): Here $X$ counts failures before the tenth success: $P(X=k)=\binom{k+9}{9}2^{-(k+10)}$ for $k\ge0$. Start with $p_0=2^{-10}$ and use $p_{k+1}/p_k=(k+10)/(2(k+1))$. The mean is $10$ and the variance is $20$. If the variable instead counts total trials to the tenth success, use $X+10$; its support starts at $10$ and its variance is unchanged.

These conventions are stated explicitly because geometric and negative-binomial distribution names alone do not uniquely specify the counted quantity.

def inverse_finite(support, probabilities, u):
    support = np.asarray(support)
    probabilities = np.asarray(probabilities, dtype=float)
    assert len(support) == len(probabilities)
    assert np.all(probabilities >= 0) and np.isclose(probabilities.sum(), 1)
    cdf = np.cumsum(probabilities)
    cdf[-1] = 1.0  # remove floating-point summation drift on finite support
    return support[np.searchsorted(cdf, u, side='left')]

def inverse_nbin_failures(u, r=10, p=.5):
    # Grow a genuine CDF until every uniform draw is covered.
    masses = [p**r]
    cumulative = [masses[0]]
    k = 0
    while cumulative[-1] < np.max(u):
        next_mass = masses[-1] * (k+r)/(k+1) * (1-p)
        next_cdf = cumulative[-1] + next_mass
        if next_cdf == cumulative[-1]:
            raise FloatingPointError('CDF accumulation stalled; use higher precision.')
        masses.append(next_mass)
        cumulative.append(next_cdf)
        k += 1
    return np.searchsorted(cumulative, u, side='left'), cumulative[-1], k

3. Acceptance-rejection and Box-Muller sampling¶

General correctness of rejection sampling¶

Suppose the target density satisfies $f\le Mq$. Independently draw $Y\sim q$ and $U\sim\mathrm{Unif}(0,1)$, accepting if $U\le f(Y)/(Mq(Y))$. For any measurable set $B$, $$P(Y\in B,\mathrm{accept})=\int_Bq(y)\frac{f(y)}{Mq(y)}dy=\frac1M\int_B f(y)dy.$$ Integrating over the support gives $P(\mathrm{accept})=1/M$; conditioning on acceptance gives the target density $f$.

3(a). Beta(2,4)¶

$$f(x)=\frac{\Gamma(6)}{\Gamma(2)\Gamma(4)}x(1-x)^3=20x(1-x)^3,\quad0<x<1.$$ Choose the uniform proposal $q(x)=1$ on $(0,1)$. Since $f'(x)=20(1-x)^2(1-4x)$, the global maximum occurs at $x=1/4$: $$M=f(1/4)=\frac{135}{64},\qquad P(\mathrm{accept})=\frac{64}{135}.$$ Draw $Y\sim\mathrm{Unif}(0,1)$ and accept with probability $20Y(1-Y)^3/M$. The expected number of proposals per output is $135/64$. The target mean is $1/3$ and variance is $2/63$.

3(b). Two standard Normal samplers¶

Box-Muller: Independently draw $U_1,U_2\sim\mathrm{Unif}(0,1)$ and define $$R=\sqrt{-2\log U_1},\quad\Theta=2\pi U_2,\quad Z_1=R\cos\Theta,\quad Z_2=R\sin\Theta.$$ Two uniform variates produce two independent standard Normal variates, with no rejection.

Acceptance-rejection: Choose the Laplace proposal $q(x)=\tfrac12e^{-|x|}$. Generate it by inverse transform: if $u<1/2$, let $Y=\log(2u)$; otherwise let $Y=-\log(2(1-u))$. Then $$\frac{\phi(x)}{q(x)}=\sqrt{\frac2\pi}\exp(-x^2/2+|x|) =\sqrt{\frac{2e}\pi}\exp[-(|x|-1)^2/2].$$ The smallest valid envelope constant is $M=\sqrt{2e/\pi}$. Thus accept if $$U\le\exp[-(|Y|-1)^2/2],\qquad P(\mathrm{accept})=\sqrt{\frac\pi{2e}}.$$ The Laplace tails are heavier than Normal tails, so this envelope is valid on the entire real line. A uniform proposal on a bounded interval cannot envelope the full Normal density.

def rejection_sample(n, propose, accept_probability, generator=rng):
    result = []
    kept = proposals = accepted_total = 0
    while kept < n:
        batch_size = max(1024, n-kept)
        y = propose(batch_size, generator)
        accepted = y[generator.random(batch_size) <= accept_probability(y)]
        result.append(accepted[:n-kept])
        kept += min(len(accepted), n-kept)
        proposals += batch_size
        accepted_total += len(accepted)
    # Include surplus accepted proposals in the acceptance-rate denominator/numerator.
    return np.concatenate(result), proposals, accepted_total

def box_muller(n, generator=rng):

    radius = np.sqrt(-2*np.log(open_uniform(pairs,generator)))
    theta = 2*np.pi*open_uniform(pairs,generator)
    return np.column_stack((radius*np.cos(theta), radius*np.sin(theta))).ravel()[:n]

3(c). Proof of the Box-Muller method¶

For $r>0$, $$P(R\le r)=P(U_1\ge e^{-r^2/2})=1-e^{-r^2/2}.$$ Consequently, $$f_R(r)=re^{-r^2/2},\quad r>0;\qquad f_\Theta(\theta)=1/(2\pi),\quad0\le\theta<2\pi.$$ The variables $R$ and $\Theta$ are independent because $U_1$ and $U_2$ are independent. The polar transformation $(z_1,z_2)=(r\cos\theta,r\sin\theta)$ has absolute Jacobian determinant $r$. Apart from the origin and angular boundary, which have probability zero, $$f_{Z_1,Z_2}(z_1,z_2)=\frac{r e^{-r^2/2}}{2\pi r} =\frac{e^{-z_1^2/2}}{\sqrt{2\pi}}\frac{e^{-z_2^2/2}}{\sqrt{2\pi}}.$$ The joint density factors into two standard Normal densities, proving both Normality and independence. The reported sample correlation is an auxiliary diagnostic, not a proof of independence.

4. From acceptance-rejection to lossless speculative decoding¶

The vocabulary is $\mathcal V=\{A,B,C,D\}$, with distributions:

Token Target $p(x)$ Draft $q(x)$
A $2/5$ $1/5$
B $3/10$ $2/5$
C $1/5$ $1/10$

4(a). Uniformity under restriction¶

1. For any measurable $C\subseteq S$, $$P(Z\in C\mid Z\in S)=\frac{P(Z\in C)}{P(Z\in S)} =\frac{|C|/|R|}{|S|/|R|}=\frac{|C|}{|S|}.$$ This is precisely the defining property of $\mathrm{Unif}(S)$. For an arbitrary measurable set $B$, apply the same argument to $C=B\cap S$.

2. Every unit of area initially has the same probability density. Removing points outside $S$ changes only the common normalization constant, preserving relative probabilities within $S$. For sampling a nonuniform density, draw uniformly under $Mq(x)$ and keep points lying under $p(x)$. The retained points are uniform under the target curve; projecting onto the horizontal axis yields probabilities proportional to the target's vertical strip areas.

4(b). Classical acceptance-rejection¶

1-2. The target-to-proposal ratios and minimum envelope constant are $$\left(\frac{p(A)}{q(A)},\frac{p(B)}{q(B)},\frac{p(C)}{q(C)},\frac{p(D)}{q(D)}\right) =(2,3/4,2,1/3),\qquad M^*=2.$$

Token $a_{\rm classical}(x)=p(x)/(2q(x))$ $q(x)a_{\rm classical}(x)$
A $1$ $1/5$
B $3/8$ $3/20$
C $1$ $1/10$
D $1/6$ $1/20$

3. Summing the accepted masses gives $$P(\mathrm{accept})=\sum_xq(x)\frac{p(x)}{M^*q(x)}=\frac1{M^*}\sum_xp(x)=\frac1{M^*}=\frac12.$$ Conditioned on acceptance, the output probability is $(p(x)/2)/(1/2)=p(x)$.

4. Independent repetitions have success probability $s=1/2$. The number of proposals $T\in\{1,2,\ldots\}$ has first-success distribution $P(T=t)=(1-s)^{t-1}s$. Therefore, $$E[T]=\sum_{t\ge1}P(T\ge t)=\sum_{t\ge1}(1-s)^{t-1}=1/s=2.$$

4(c). Overlap acceptance¶

1-2. Define $a(x)=\min(1,p(x)/q(x))$ on the proposal support. If $p(x)\ge q(x)>0$, the ratio is at least one, so the token is always accepted. Moreover, $$P(Y=x,\mathrm{accept})=q(x)\min(1,p(x)/q(x))=\min(p(x),q(x)).$$

Token $a(x)$ Accepted mass $m(x)$
A $1$ $1/5$
B $3/4$ $3/10$
C $1$ $1/10$
D $1/3$ $1/10$

Thus $\alpha=1/5+3/10+1/10+1/10=7/10$.

3. $P(Y=A\mid\mathrm{accept})=(1/5)/(7/10)=2/7\ne2/5=p(A)$. Accepted tokens have distribution $m(x)/\alpha$, which generally differs from $p(x)$. Repeatedly proposing until this overlap rule accepts would therefore not produce exact target samples.

4. Represent each token by a unit-width strip with heights $p(x)$ and $q(x)$. The intersection height, and hence its area, is $m(x)=\min(p(x),q(x))$. A uniform point in $R_q$ can be generated by drawing $Y\sim q$, a uniform horizontal location within its strip, and height $H\mid Y\sim\mathrm{Unif}(0,q(Y))$. Accepting when $H\le p(Y)$ restricts the point to $R_p\cap R_q$. By (a), retained points are uniform on this intersection, and their token probabilities are intersection strip areas divided by total intersection area: $m(x)/\alpha$.

4(d). Residual correction¶

1. Set $d(x)=(p(x)-q(x))_+$. Direct calculation gives $$d=(1/5,0,1/10,0),\quad\delta=\sum_xd(x)=3/10,\quad r=(2/3,0,1/3,0).$$

2. Since $q(x)-\min(p(x),q(x))=(q(x)-p(x))_+$, $$P(\mathrm{reject})=1-\alpha=\sum_x(q(x)-p(x))_+.$$ Also $\sum_x(p(x)-q(x))=0$, so total positive and negative deviations are equal. Hence $$\sum_x(q(x)-p(x))_+=\sum_x(p(x)-q(x))_+=\delta=3/10.$$

3. For arbitrary probability distributions $p,q$ on a finite vocabulary, the identity $$p(x)=\min(p(x),q(x))+(p(x)-q(x))_+$$ holds by considering $p(x)\le q(x)$ and $p(x)>q(x)$ separately. When $\delta>0$, draw a replacement independently from $r=d/\delta$ after rejection. Then $$P(X=x)=P(Y=x,\mathrm{accept})+P(\mathrm{reject})r(x) =\min(p(x),q(x))+\delta\frac{(p(x)-q(x))_+}{\delta}=p(x).$$ If $q(x)=0$, the draft never proposes $x$, so its acceptance ratio need not be evaluated; the residual supplies any missing target mass. If $\delta=0$, normalization implies $p=q$, no rejection occurs, and no residual distribution is needed. Thus the proof covers zero-probability cases as well.

4(e). Total variation and maximal coupling¶

1. Using $\min(p,q)=(p+q-|p-q|)/2$ and summing, $$\alpha=\sum_x\min(p(x),q(x))=1-\frac12\sum_x|p(x)-q(x)|=1-D_{\rm TV}(p,q).$$ Here $D_{\rm TV}=\tfrac12(1/5+1/10+1/10+1/5)=3/10$, so $\alpha=7/10$, agreeing with (c).

2. For any coupling $(X,Y)$ with marginals $p,q$, $$P(X=x,Y=x)\le P(X=x)=p(x),\qquad P(X=x,Y=x)\le P(Y=x)=q(x).$$ The diagonal events are disjoint, so $P(X=Y)\le\sum_x\min(p(x),q(x))$.

3. In speculative sampling, acceptance sets $X=Y$. Rejection can occur only at tokens with $q(Y)>p(Y)$, whereas residual replacements have support only where $p(X)>q(X)$. These supports are disjoint, so rejection cannot yield $X=Y$. Therefore, $$P(X=Y)=P(\mathrm{accept})=\sum_x\min(p(x),q(x)).$$ Together with $X\sim p$ from (d) and $Y\sim q$ by construction, this attains the upper bound for all couplings and is therefore a maximal coupling. A draft closer to the target in TV distance has a greater probability of having its proposal reused. Missing draft support does not invalidate the construction.

4(f). Autoregressive sequences¶

Conditioned on the prefix $X_1=A$, the given distributions yield:

Token $p(x\mid A)$ $q(x\mid A)$ Acceptance $a(x\mid A)$ Accepted mass $d(x\mid A)$ $r(x\mid A)$
A $1/2$ $1/4$ $1$ $1/4$ $1/4$ $1/2$
B $1/4$ $1/2$ $1/2$ $1/4$ $0$ $0$
C $1/4$ $0$ N/A (never proposed) $0$ $1/4$ $1/2$
D $0$ $1/4$ $0$ $0$ $0$ $0$

1. The draft can propose $A,B,D$, whose acceptance probabilities are $1,1/2,0$. Total acceptance is $1/4+1/4=1/2$, and rejection is $1/2$. The acceptance ratio for $C$ is undefined and unnecessary because it cannot be proposed.

2. The unnormalized residual is $(1/4,0,1/4,0)$, giving $r=(1/2,0,1/2,0)$. Thus $$P(X_2=C\mid X_1=A)=0+\frac12\cdot\frac12=\frac14.$$ Although the draft never proposes $C$, residual correction supplies its exact target probability. The output probabilities of $A,B,D$ are likewise $1/2,1/4,0$.

3. Using the original first-token probability $p(A)=2/5$, $$P(X_1=A,X_2=C)=P(X_1=A)P(X_2=C\mid X_1=A)=\frac25\cdot\frac14=\boxed{\frac1{10}}.$$ This agrees with direct autoregressive sampling from the target.

4. At every positive-probability history $h=x_{1:t-1}$, apply (d) to the conditional distributions $p(\cdot\mid h),q(\cdot\mid h)$. The resulting next-token conditional distribution is exactly $p(\cdot\mid h)$. The same argument applies at the first position. By the chain rule, or induction on prefix length, $$P_{\rm alg}(X_{1:T}=x_{1:T})=\prod_{t=1}^T p(x_t\mid x_{1:t-1}).$$ A sequence with zero target probability is excluded by the corresponding zero conditional probability; arbitrary definitions at unreachable histories do not affect the joint law.

In a draft block, tokens after the first rejected position, and their verification probabilities, were computed using the original draft prefix. A correction changes that prefix. Later candidates generally no longer follow $q$ conditioned on the actual prefix, and the old verification probabilities no longer give the required target conditionals. The standard algorithm must discard the remaining draft suffix and restart from the corrected output prefix. If all $K$ candidates are accepted, the additional token is sampled from the target distribution conditioned on the full accepted prefix.

4(g). Why can speculative decoding be faster?¶

1. Under the stipulated independent, constant acceptance probability $\alpha=7/10$, $$P(L=\ell)=\alpha^\ell(1-\alpha),\quad0\le\ell<K;\qquad P(L=K)=\alpha^K.$$

$\ell$ $P(L=\ell)$
0 $3/10$
1 $21/100$
2 $147/1000$
3 $343/1000$

These sum to $(300+210+147+343)/1000=1$.

2. For integer-valued $L\in\{0,\ldots,K\}$, $$L+1=\sum_{j=0}^K\mathbf1\{L\ge j\},\qquad P(L\ge j)=\alpha^j.$$ Taking expectations yields $$E[L+1]=\sum_{j=0}^K\alpha^j=\frac{1-\alpha^{K+1}}{1-\alpha}\quad(\alpha\ne1).$$ For $\alpha=1$, the expectation is $K+1$; for $\alpha=0$, it is $1$. In this problem, $$E[L+1]=1+\frac7{10}+\frac{49}{100}+\frac{343}{1000}=\boxed{\frac{2533}{1000}=2.533}.$$ Equivalently, the probability table gives $1(0.3)+2(0.21)+3(0.147)+4(0.343)=2.533$.

3. The value 2.533 counts emitted tokens per verification round, rather than measuring wall-clock speedup. Two practical factors are:

  1. Time spent generating $K$ sequential draft candidates, plus residual computation, sampling, and scheduling overhead.
  2. The cost of target verification, memory bandwidth, and KV-cache access or rollback. Verifying a block is not necessarily as cheap as decoding one token.

A rough cost model is $$\mathrm{speedup}\approx\frac{E[L+1]c_{\rm target}}{Kc_{\rm draft}+c_{\rm verify}(K)+c_{\rm overhead}}.$$ Acceleration requires sufficiently low extra costs. Real acceptance probabilities vary with the prefix and position and need not be independent, so the geometric sum applies to the simplified assumptions in this question.

Final synthesis (fewer than 100 words)¶

Uniform restriction underlies classical acceptance-rejection. Overlap acceptance reuses draft proposals with $P(Y=x,\mathrm{accept})=\min\{p(x),q(x)\}$. Residual correction supplies the missing mass because $p(x)=\min\{p(x),q(x)\}+(p(x)-q(x))_+$. This constructs a maximal coupling, with $P(\mathrm{accept})=1-D_{\mathrm{TV}}(p,q)$. Applying these identities at each actual prefix preserves the autoregressive target distribution. Cheap drafts enable parallel target verification; accepted prefixes amortize expensive target evaluations across multiple emitted tokens. Rejected suffixes are discarded and regenerated from the corrected prefix. Acceleration depends on acceptance rates and computational overhead, while the corrected output distribution remains exact.
