# 校园浅色 UI 核对

## 参考与方法

- 用户参考及最初完整概念：[主页](home-concept.png)、[入口](welcome-concept.png)。最终导航以用户最新的[手绘参考](nav-reference.png)为准。其他追加要求：浅色导航、乳黄色拼单按钮、参考图风格的地图展示。
- 使用 frontend-app-builder skill：先生成整屏概念和独立插画，再实现原生组件。
- 仓库 AGENTS.md 要求只从命令行运行测试，因此使用命令行启动的无头 Chrome 检查实际 Taro H5 构建，没有操控用户桌面。H5 宿主页补齐了 Taro 的 rem 标定；不把它当作微信模拟器。
- 视口：390×844、320×700，以及参考稿原始尺寸853×1844。最终截图位于 `apps/miniapp/artifacts/campus-play-review/`。
- 已用 view_image 直接查看参考稿和实际截图，对照布局、字体、插画、圆角和控件。

## 文案差异

主标题、拼单动作、功能卡、地图和模块标题均与参考稿保持一致。去掉生成图中多余英文句点。数量和模块名称继续读取共享契约；敏感模块保留真实标签。新增“收起模块”为展开功能必要状态。非官方平台说明保留项目完整版本。没有新增宣传数据或虚构使用人数。

## 有意差异与边界

- 深色导航、饱和黄色按钮按照用户新指令改成浅色和乳黄；旧气泡导航按用户最新参考替换为手绘胶囊。
- 地图缩略图是风格插画，不代表真实地理；打开后仍是项目现有校园地图。
- 其余模块通过展开显示，保持18个一级入口的契约来源；敏感标签沿用项目的黄/红提示规则。
- 原生顶部微信胶囊由微信提供，H5截图不含该区域。
- 修复了 H5 构建中重复安装的 Taro Router 配置单例问题，预览构建统一解析到同一个路由包。
- 微信 CLI 测试实际返回 `IDE service port disabled`，因此没有将静态构建或 H5 视觉核对称为微信模拟器验证。

最终样式已按参考布局及用户追加的浅色要求逐项核对；不声称生成图的逐像素复制。
